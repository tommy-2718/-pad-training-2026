========================================
商品在庫管理システム（演習用）
Power Automate Desktop 演習手順
========================================

【起動方法】
index.html を Microsoft Edge で直接開いてください。
インターネット接続・サーバー不要で動作します。

【ログイン情報】
  ユーザーID ： admin
  パスワード ： password

【画面の構成】
  ・ログイン画面（id: loginArea）
  ・商品在庫検索画面（id: mainArea）
      商品名の部分一致と、発注要否（発注必要／発注不要）で絞り込めます。
      発注要否は「在庫数 ≦ 発注基準」のとき「発注必要」と表示されます。
      検索結果テーブルには発注基準の列も表示されます。

----------------------------------------
演習1：ログインする
----------------------------------------
手順：
  1. ユーザーID入力欄（id: loginUser）に「admin」を入力する
  2. パスワード入力欄（id: loginPassword）に「password」を入力する
  3. ログインボタン（id: loginButton）をクリックする

確認ポイント：
  - ログインに成功すると、商品在庫検索画面（id: mainArea）が表示される
  - 失敗した場合はエラーメッセージ（id: loginError）が表示される
    取得テキスト例：「ユーザーIDまたはパスワードが違います。」

----------------------------------------
演習2：商品名で検索する
----------------------------------------
手順：
  1. 商品名入力欄（id: searchInput）に「鉛筆」と入力する
  2. 検索ボタンをクリックする
  3. 「検索中...」が表示されたあと、0.5秒後に結果が表示される
  4. 検索結果テーブル（id: resultTable）から情報を取得する

取得できる情報（id: results の各行）：
  - 1列目：商品ID
  - 2列目：商品名
  - 3列目：金額
  - 4列目：在庫数
  - 5列目：発注基準
  - 6列目：発注要否（発注必要／発注不要）

メモ：
  - 「鉛筆」で2件、「シャープペン」で4件など、部分一致で複数行がヒットする

----------------------------------------
演習3：発注要否で検索する
----------------------------------------
手順：
  1. 発注要否の選択欄（id: statusFilter）で「発注必要」を選ぶ
  2. 検索ボタンをクリックする
  3. 一覧に表示された発注必要データを取得する

確認ポイント：
  - 商品名が空欄でも発注要否だけで絞り込める
  - 商品名と発注要否を両方指定した場合は AND 条件で絞り込まれる
    例：「シャープペン」＋「発注必要」→ シャープペンA・B・C の3件

----------------------------------------
演習4：0件メッセージを取得する
----------------------------------------
手順：
  1. 商品名入力欄に「存在しない商品」と入力する
  2. 検索ボタンをクリックする
  3. 0件メッセージ（id: noResultMessage）のテキストを取得する

取得テキスト：「該当する商品はありません。」

確認ポイント：
  - 0件のときはテーブルが非表示になり、noResultMessage が表示される
  - 待機アクションを使って0.5秒後に要素を取得する練習ができる

----------------------------------------
演習5：Excelへの取得（転記）の想定
----------------------------------------
ねらい：
  Web画面から取得した情報を、新しい Excel ファイルに書き出す練習。
  （同梱の「商品在庫.xlsx」は完成イメージ・答え合わせ用です）

手順（PADフロー概要）：
  1. 新しい Excel ファイルを作成し、見出し行
       「商品ID／商品名／金額／在庫数／発注基準／発注要否」を書き込む
  2. 商品在庫検索画面で商品名を空欄のまま検索ボタンをクリックする
  3. 0.5秒待機する（「検索中...」表示が終わるのを待つ）
  4. 検索結果テーブル（id: resultTable）を1行ずつ読み取り、
       商品ID・商品名・金額・在庫数・発注基準・発注要否を取得する
  5. 取得した各行を Excel の対応行に書き込む
  6. Excel ファイルを保存して閉じる

応用：
  - 発注要否の選択欄で「発注必要」を選んでから検索し、
    発注が必要な商品だけを Excel に書き出す

  loginError       ログインエラーメッセージ
  mainArea         商品在庫検索画面全体
  searchInput      商品名入力欄
  statusFilter     発注要否の選択プルダウン
  searchButton     検索ボタン

  resultTable      検索結果テーブル
  results          検索結果 tbody（各行を取得）
  noResultMessage  0件メッセージ
