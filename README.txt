========================================
請求管理システム（演習用）
Power Automate Desktop 演習手順
========================================

【起動方法】
index.html を Microsoft Edge で直接開いてください。
インターネット接続・サーバー不要で動作します。

【ログイン情報】
  ユーザーID ： admin
  パスワード ： password

----------------------------------------
演習1：ログインする
----------------------------------------
手順：
  1. ユーザーID入力欄（id: loginUser）に「admin」を入力する
  2. パスワード入力欄（id: loginPassword）に「password」を入力する
  3. ログインボタン（id: loginButton）をクリックする

確認ポイント：
  - ログインに成功すると、請求検索画面（id: mainArea）が表示される
  - 失敗した場合はエラーメッセージ（id: loginError）が表示される
    取得テキスト例：「ユーザーIDまたはパスワードが違います。」

----------------------------------------
演習2：顧客名で検索する
----------------------------------------
手順：
  1. 顧客名入力欄（id: searchInput）に「田中」と入力する
  2. 検索ボタンをクリックする
  3. 「検索中...」が表示されたあと、0.5秒後に結果が表示される
  4. 検索結果テーブル（id: resultTable）から情報を取得する

取得できる情報（id: results の各行）：
  - 1列目：顧客名
  - 2列目：請求金額
  - 3列目：ステータス

----------------------------------------
演習3：ステータスで検索する
----------------------------------------
手順：
  1. ステータス選択欄（id: statusFilter）で「未払い」を選ぶ
  2. 検索ボタンをクリックする
  3. 一覧に表示された未払いデータを取得する

確認ポイント：
  - 顧客名が空欄でもステータスだけで絞り込める
  - 顧客名とステータスを両方指定した場合は AND 条件で絞り込まれる

----------------------------------------
演習4：0件メッセージを取得する
----------------------------------------
手順：
  1. 顧客名入力欄に「存在しない会社」と入力する
  2. 検索ボタンをクリックする
  3. 0件メッセージ（id: noResultMessage）のテキストを取得する

取得テキスト：「該当する請求情報はありません。」

確認ポイント：
  - 0件のときはテーブルが非表示になり、noResultMessage が表示される
  - 待機アクションを使って0.5秒後に要素を取得する練習ができる

----------------------------------------
演習5：Excel転記の想定
----------------------------------------
手順（PADフロー概要）：
  1. Excelから顧客名リストを1件ずつ読み込む
  2. 請求検索画面の顧客名入力欄（id: searchInput）に顧客名を入力する
  3. 検索ボタンをクリックする
  4. 0.5秒待機する（検索中表示が終わるのを待つ）
  5. 検索結果テーブル（id: resultTable）の1行目から
       請求金額・ステータスを取得する
  6. Excelの対応行に書き戻す
  7. 次の顧客名でループを繰り返す

----------------------------------------
主要な要素ID 一覧
----------------------------------------
  loginArea        ログイン画面全体
  loginUser        ユーザーID入力欄
  loginPassword    パスワード入力欄
  loginButton      ログインボタン
  loginError       ログインエラーメッセージ
  mainArea         請求検索画面全体
  searchInput      顧客名入力欄
  statusFilter     ステータス選択プルダウン
  searchButton     検索ボタン
  resultCount      件数表示エリア（「検索中...」も表示）
  resultTable      検索結果テーブル
  results          検索結果 tbody（各行を取得）
  noResultMessage  0件メッセージ
